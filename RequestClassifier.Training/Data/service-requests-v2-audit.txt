SERVICE REQUESTS V2 DATASET AUDIT
=================================

Original dataset:
- Rows: 7,400
- Categories: 74
- Rows per category: 100
- Empty Text/Category: 0
- Exact duplicate Text: 0
- Malformed TSV rows: 0

Important findings:
- The original data was structurally valid but heavily template-based.
- 203 sentence patterns were shared by more than one category.
- Several generic sentences appeared across all 74 categories more than 900 times.
- Important real-world terms were absent from the original data:
  lamba: 0, kanalizasyon: 0, rögar: 0, taksi: 0,
  reklam: 0, tabela: 0, içme suyu: 0, bulanık: 0,
  personel: 0, kaba: 0.
- 'park' appeared in all 100 Otopark rows, which explains why park-lighting
  requests could be pulled toward Otopark.
